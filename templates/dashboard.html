Perhatian sebelum mengunggah

Ukuran maksimal 5 MB per file, dan hanya format DOCX, PDF, TXT, PNG, JPG yang dapat diunggah. File yang melebihi batas atau berformat lain akan otomatis ditolak dan tidak tersimpan.

Cara Mengunggah File

  1. Pilih file. Klik tombol Unggah File di sidebar, atau seret file langsung ke kotak putus-putus di halaman utama.
  2. Tunggu proses enkripsi. File dienkripsi di perangkat Anda dengan ChaCha20-Poly1305 sebelum dikirim, sehingga server tidak pernah menerima file aslinya.
  3. File muncul di daftar. Klik kartu file untuk melihat isinya, atau gunakan ikon titik tiga untuk mengunduh dan menghapus.
